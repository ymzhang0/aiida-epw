# Welcome to aiida-epw's documentation!

`aiida-epw` is an AiiDA plugin designed to automate and manage EPW workflows.

This plugin is strongly based on the existing workflows in `aiida-quantumespresso` and `aiida-wannier90-workflows`.

It provides functionalities for transport and superconductivity calculations using EPW.
